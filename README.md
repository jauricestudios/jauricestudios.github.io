## Projects

### B6 Transmission Headroom & Scottish Wind Balancing

This project looks at whether day-ahead B6 transmission headroom contains useful information about later Scottish wind balancing activity.

I combined NESO boundary data with wind and demand forecasts and Balancing Mechanism actions. The final sample contains 42,332 settlement periods.

Adding B6 headroom to the event model increased ROC AUC from 0.817 to 0.862. The improvement was much smaller when predicting the exact volume of balancing activity.

### Norwegian Gas Outages & TTF

This project looks at how near-term TTF prices behave around Norwegian gas outage announcements.

I reconstructed Gassco outage messages and revisions so that the timing of the first announcement could be aligned properly with market dates. The dataset contains 376 messages, including 188 first announcements.
